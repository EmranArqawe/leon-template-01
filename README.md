# 🎨 Leon | Creative Agency Template

A modern, responsive agency landing page built to demonstrate proficiency in semantic HTML5 structure and clean CSS3 styling. The template focuses on minimal design principles, modern typography, and seamless layout performance across all devices.

---

## 🎨 Preview & Demo

* **Live Site URL:** [Click here to view live site](https://emranarqawe.github.io/leon-template-01/)

---

## 🚀 Key Features

* **Fully Responsive UI:** Adaptive layout engineered with CSS Grid and Flexbox to ensure consistent viewing experiences across desktop, tablet, and mobile screens.
* **Minimalist Aesthetic:** Designed with a focus on typography, strategic whitespace, and visual balance.
* **Semantic HTML Architecture:** Structured with standard HTML5 elements for accessible and search-engine-friendly web organization.
* **Interactive UI Feedback:** Enhanced user interaction through custom CSS transitions and responsive navigation components.

---

## 🛠️ Built With

* **Frontend:** HTML5
* **Styling:** CSS3 (Flexbox, CSS Grid, Custom Variables, Media Queries)
* **Icons & Fonts:** Font Awesome, Google Fonts (*Work Sans*)

---

## 📦 How to Run the Project

1. Clone or download this repository.
2. Ensure all project folders (`css`, `image`, `webfonts`) remain in the same root directory.
3. Open `index.html` in any modern web browser to view the page.
